# 📝 To-Do List Application

A clean, interactive Python application built to help users manage daily tasks, boost productivity, and keep track of upcoming GCSE study goals efficiently.

## 🚀 Features
*   **Add Tasks:** Quickly add new tasks with descriptions or priority levels.
*   **Track Status:** Check off completed items to visualize daily progress.
*   **Remove & Clear:** Clean up old or finished items to keep your list organized.

---

## 🛠️ How to Run

Follow these quick steps to run the task manager locally on your machine:

### 1. Clone the Repository
Open your terminal or command prompt and execute:
```bash
git clone https://github.com
cd to-do-list
```

### 2. Launch the Application
Execute the script using Python 3:
```bash
python todo.py
```
*(Note: If your main file has a different name, replace `todo.py` with your exact filename like `main.py` or `app.py`).*
